# Segurança

O Gestão de Processos pode armazenar dados pessoais e informações relacionadas a processos judiciais.

## Não publique dados sensíveis

Não envie para o repositório:

- chaves da API DataJud;
- senhas;
- arquivos `.env`;
- bancos SQLite usados em produção;
- backups;
- logs contendo dados pessoais ou informações confidenciais.

## Comunicação de vulnerabilidades

Se você encontrar uma vulnerabilidade de segurança, evite publicar detalhes técnicos sensíveis em uma issue pública.

Entre em contato diretamente com o mantenedor do projeto para que o problema possa ser analisado e corrigido antes da divulgação pública.

## Boas práticas

- mantenha as dependências atualizadas;
- use senhas fortes;
- mantenha backups;
- não exponha a aplicação local para a internet sem uma revisão específica de segurança;
- trate o banco e os backups como dados confidenciais.
